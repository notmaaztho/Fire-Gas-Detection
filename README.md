ESP32 Gas Leakage and Fire Detection System

Project Overview

This project uses an ESP32 microcontroller to detect gas leakage and fire using sensors. It provides alerts to help people identify potentially dangerous situations.

Components Used

1. ESP32 development board
2. Gas sensor
3. Flame sensor
4. LEDs
5. ISD1820 voice alarm module
6. SG90 servo motor
7. Connecting wires

Features

- Detects gas leakage.
- Detects fire using a flame sensor.
- Provides visual alerts using LEDs.
- Provides a voice alarm.
- Supports optional Wi-Fi notifications.

Technology Used

- Domain: Internet of Things (IoT)
- Platform: ESP32
- Programming Language: Arduino C/C++
- Application Area: Gas leakage and fire safety

Safety Notice

This is an educational prototype, not a certified safety system. Always use certified gas and fire alarms for real-world protection.
